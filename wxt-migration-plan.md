# Convert slack2md to WXT

## Context

The slack2md Firefox extension is currently a vanilla JS project (MV2, no build system, no dependencies). We're converting it to use WXT (latest, ~0.20.x) with TypeScript and pnpm as the package manager. This gives us a modern build pipeline, hot reloading during development, and TypeScript type safety. Target is Firefox only, staying on MV2.

Testing and linting toolchain: vitest + happy-dom, @testing-library/jest-dom, @testing-library/user-event, and oxlint for fast linting.

## Target Structure

```
slack2md/
  entrypoints/
    background.ts          # Background entrypoint (defineBackground)
    content.ts             # Content script entrypoint (defineContentScript)
  public/
    icon.svg               # Static asset (copied as-is)
  test/
    content.test.ts        # Tests for htmlToMarkdown and content script logic
  wxt.config.ts            # WXT config (manifest settings, permissions, commands)
  vitest.config.ts         # Vitest configuration with happy-dom
  package.json             # Scripts + metadata
  tsconfig.json            # Extends .wxt/tsconfig.json
  .gitignore               # Updated for WXT output dirs
  README.md                # Updated install/dev instructions
```

## Steps

### 1. Initialize project with pnpm
- Run `pnpm init` to create `package.json`
- Install deps: `pnpm add -D wxt vitest happy-dom @testing-library/jest-dom @testing-library/user-event oxlint`
- Set `name` ("slack2md"), `version` ("1.1.0"), `description`, `"type": "module"`, `"private": true`
- Add scripts:
  - `"dev": "wxt -b firefox"`
  - `"build": "wxt build -b firefox"`
  - `"zip": "wxt zip -b firefox"`
  - `"test": "vitest run"`
  - `"test:watch": "vitest"`
  - `"lint": "oxlint ."`
  - `"check": "oxlint . && vitest run"`
  - `"postinstall": "wxt prepare"`

### 2. Create `wxt.config.ts`
- Import `defineConfig` from `'wxt'` (not auto-imported in config files)
- Use MV2 manifest keys since we're targeting Firefox MV2:
  - `browser_action: { default_icon: "icon.svg", default_title: "Copy Slack selection as Markdown" }`
  - `permissions: ["activeTab"]` (drop `clipboardWrite` — the code uses `navigator.clipboard.writeText()` which doesn't need it)
  - `commands` with `copy-as-markdown` keyboard shortcut (Ctrl+Shift+M / MacCtrl+Shift+M)
  - `icons: { 48: "/icon.svg" }`

### 3. Create `entrypoints/background.ts`
- Use `defineBackground(() => { ... })` shorthand
- Inside main: register `browser.browserAction.onClicked` listener (MV2 API)
- Inside main: register `browser.commands.onCommand` listener for "copy-as-markdown"
- Both send `{ action: "copy-as-markdown" }` message to active tab via `browser.tabs.sendMessage`

### 4. Create `entrypoints/content.ts`
- Use `defineContentScript({ matches: ["*://*.slack.com/*"], main() { ... } })`
- Define `htmlToMarkdown()` and `showToast()` at module scope and export them (pure functions, no browser APIs — enables direct testing)
- `copySelectionAsMarkdown()` also at module scope and exported (uses DOM/clipboard but no extension APIs)
- Register `browser.runtime.onMessage` listener inside `main()` (this is the only part that needs browser extension APIs)

### 5. Move `icon.svg` to `public/icon.svg`

### 6. Create `tsconfig.json`
```json
{ "extends": ".wxt/tsconfig.json" }
```

### 7. Create `vitest.config.ts`
- Use happy-dom as the test environment
- Configure path aliases to match WXT's `@`/`~` aliases

### 8. Create initial tests (`test/content.test.ts`)
- Test `htmlToMarkdown()` conversion for each supported element (bold, italic, strikethrough, code, pre, links, br, blockquotes, lists)
- Test `copySelectionAsMarkdown()` clipboard behavior using happy-dom
- Use @testing-library/jest-dom matchers for DOM assertions
- Export `htmlToMarkdown` and `copySelectionAsMarkdown` from content.ts for testability (define them at module scope, outside `main`, since they are pure functions with no browser API usage)

### 9. Update `.gitignore`
Add: `.output/`, `.wxt/`, `node_modules/`

### 10. Delete old files
- Remove `manifest.json` (generated by WXT)
- Remove `background.js` (replaced by `entrypoints/background.ts`)
- Remove `content.js` (replaced by `entrypoints/content.ts`)
- Remove `icon.svg` from root (moved to `public/`)

### 11. Update README.md
- Update install instructions to reference `pnpm dev` for development
- Update build instructions to reference `pnpm build`
- Fix existing errors: README says "Alt+Shift+C" and mentions a context menu — actual shortcut is Ctrl+Shift+M and there is no context menu

### 12. Run `pnpm install`, `pnpm check`, and `pnpm dev` to verify

## Verification
1. `pnpm install` succeeds without errors
2. `pnpm test` — all tests pass
3. `pnpm lint` — no lint errors
4. `pnpm check` — lint + tests pass together
5. `pnpm dev` launches Firefox with the extension loaded
6. Navigate to any `*.slack.com` page
7. Select text and click toolbar icon — text is copied as markdown
8. Ctrl+Shift+M keyboard shortcut works
9. Toast notification appears
10. `pnpm build` produces output in `.output/`
